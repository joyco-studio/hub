## What is Markdown?

[Markdown](https://md.joyco.studio) is a web tool that previews and renders Markdown files in real time. Drop a `.md`, `.markdown`, `.mdx` or `.txt` file anywhere on the page (or pick one with the file button) and it renders instantly, no install or build step required.

It supports GitHub Flavored Markdown including tables, task lists and strikethrough, ships syntax highlighting for code blocks, and styles everything with Tailwind Typography. The theme follows your system preference automatically.
